# 业务流 SOP：整批服务器到货入库（含原装配件）

> 场景基准：供应商「优普计算机有限公司」发货 10 台华为服务器，每台含 80 根三星内存。
> 本流程已于 2026-08-03 在系统中完整走通（10 台服务器 + 800 根内存全部入账）。

## 0. 业务流总览

```
供应商发货 ──► ①基础数据准备 ──► ②服务器批量建档 ──► ③配件批量入库 ──► ④核对与流转
（到货单）     （供应商/型号）     （CSV两段式导入）   （原装绑定/在库）   （列表/余量/履历）
```

**角色分工**：
| 环节 | 角色 | 页面 |
|---|---|---|
| 供应商/型号/品牌/库位维护 | 管理员 | 供应商、型号管理、品牌管理、存放位置 |
| 服务器建档（单台/批量） | 管理员 | 服务器管理 |
| 配件入库（单件/批量） | 操作员及以上 | 分类入库 |
| 核对与后续流转 | 所有人 | 配件列表、可调余量、审批中心 |

---

## 1. 基础数据准备（一次性，管理员）

| # | 操作 | 入口 | 说明 |
|---|---|---|---|
| 1.1 | 供应商建档 | 侧边栏「供应商」→ 新增 | 名称必填，后续入库下拉与批量导入都会引用它 |
| 1.2 | 品牌确认 | 「品牌管理」 | 三星已在名录（适用：内存/固态硬盘），无需操作 |
| 1.3 | 型号建档 | 「型号管理」→ 新增 | 例：三星 32G DDR5 4800 RDIMM，规格按类型校验（容量GB/内存类型/频率MHz）。**入库的"型号名称"必须与这里一字不差** |
| 1.4 | 库位确认 | 「存放位置」 | 非原装件才用；注意库位可限定允许的配件类型 |

>  skipped 的场景数据：优普计算机有限公司（id=5）、三星 32G DDR5 4800 RDIMM（id=10）。

## 2. 服务器批量建档（管理员）

1. 「服务器管理」→ 点 **「批量导入 / 导出」** → **「下载导入模板」**。
2. 按模板填 10 行（列序不要动）：资产编号（SRV-HW-101~110）、型号（华为 2288H V6）、机房/机柜/U位、运维部门（基础组）、供应商（优普计算机有限公司，**须在名录**）、合同号（HT-2026-YP-001）、所属项目、产权单位、维保到位时间、设备到货日期、采购金额、运行状态（未投运）。
3. **「选择 CSV 文件」→「开始校验」**：系统逐行给出 ✓/✗ 及原因，全部通过才能点**「确认导入」**。
4. 单台补录也可用「+ 新增服务器」表单（供应商为下拉选择）。

> 校验规则：资产编号库内/文件内不重、部门合法、供应商在名录、日期 YYYY-MM-DD、金额为数字。**任一行有错，整批不入库**——修正后重新上传即可。

## 3. 配件批量入库（操作员及以上）

进「分类入库」→ 选「内存」→ 点 **「批量导入（CSV）」** → 下载本类模板。两种来源填法：

### 3.1 服务器原装（随服务器一起来，本场景）
每行只需：**配件类型、型号名称、固定资产编号、设备序列（SN）号、来源=服务器原装、关联服务器=服务器资产编号、采购金额、可调配标记、备注**。
- 供应商/合同号/项目/产权/维保/到货日期/**存放位置**全部由服务器档案**自动带出**，留空即可；
- 配件入库后**直接在装（在用）**，位置 = 该服务器，履历为一条「入库 → 在用（服务器）」；
- 服务器档案缺供应商/合同号/运维部门时整行报错的，先去服务器管理补全。

### 3.2 独立合同采购 / 框招正偏移（单独买的备件）
**全字段手填**：存放位置（"库房/货位"格式，须在库位表存在且类型兼容）、运维部门、供应商（须在名录）、合同号、所属项目、产权单位、到货验收日期、维保到位时间 + 通用字段。
- 入库后为**在库**，进入可调余量统计（产权=本单位 ∩ 通用可调时）。

### 3.3 校验与提交
「选择 CSV 文件」→「开始校验」→ 预览表逐行核对 → 全绿后「确认导入」。
800 行整批校验+入库实测一次通过。

## 4. 核对与后续流转

| 核对项 | 入口 | 预期 |
|---|---|---|
| 数量与状态 | 配件列表，搜索 `FA-HW-` | 800 件全部「在用」 |
| 分布 | 配件列表位置列 / 服务器管理 | 每台服务器 80 根 |
| 合同信息 | 任一配件详情/履历 | 供应商、合同号、维保与服务器档案一致 |
| 履历 | 配件 → 履历 | 单条「入库 → 在用（服务器）」 |
| 可调余量 | 「可调余量」 | 原装件在用，不计入在库余量（口径正确） |
| 台账 | 批量导入面板的「导出 CSV」 | 随时可导全量或按类型 |

后续流转照常：服务器「投运」切换（投运锁拆自动生效）、借出/调拨/报废三级审批、盘点。

## 5. 常见校验错误对照

| 报错 | 原因 | 处理 |
|---|---|---|
| 型号「内存/xxx」不在型号库 | 型号名称与型号库不一致 | 到型号管理核对名称（含空格） |
| 供应商「xxx」不在名录中 | 名录没有 | 先建档供应商 |
| 资产编号已存在 / 文件内重复 | 编号冲突 | 更换编号后重新上传 |
| 服务器「xxx」档案缺少供应商/合同号/运维部门 | 原装联动缺档案 | 服务器管理 → 编辑补全 |
| 存放位置「xxx」不存在 | 须为"库房/货位"且在库位表中 | 存放位置页核对 |
| 存放位置仅允许：算力卡 | 库位类型限制 | 换兼容库位 |
| 表头含未知列 | 改过模板列名 | 重新下载模板 |

## 6. 一句话流程卡

> **先名录、再型号；服务器先建档（可批量）；配件原装绑服务器、散件填全字段；上传先校验、全绿才导入；导入后列表+余量+履历三核对。**
